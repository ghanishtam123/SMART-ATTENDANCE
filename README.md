# 🎓 Smart Attendance System

AI-based attendance system using face recognition.

## 🚀 Features
- Face Recognition
- Admin Dashboard
- Attendance Tracking

## 🛠️ Tech Stack
- Frontend: React
- Backend: Node.js, Express
- Database: MongoDB
- AI: Python, OpenCV

## ⚙️ How to Run

### AI Service
cd ai-service  
python -m venv venv  
venv\Scripts\activate  
pip install -r requirements.txt  
python main.py  

### Backend
cd backend  
npm install  
npm run dev  

### Frontend
cd frontend  
npm install  
npm run dev
